# Parreira.ca scripts

Ready-to-film scripts for the "If I was…" series. The format and rules are in `social/parreira-ideas.md` on the code branch.

How to read them: **VO** is what Matt says (captions follow it 2–3 words at a time). **SCREEN** is what builds on the
TV above him. Bracketed tags like `[CFIB, Oct. 2026]` are the small source labels on screen. Times are rough; aim for 60–90 s.

- [If I bought a 30-year-old HVAC company](2026-10-28-if-i-bought-an-hvac-company.md) · business
- [If I ran an Ontario university](2026-10-28-if-i-ran-an-ontario-university.md) · post-secondary
- [If I was B.C.'s new premier](2026-10-28-if-i-was-bcs-new-premier.md) · politics

Before filming, re-check any number older than a month; the sources are listed at the bottom of each script.
